Sobre o Hyper Futuro X

Uma interface independente para organizar estudos, com layout responsivo, armazenamento local, planejamento de tarefas, calendário e temporizador. Não é um produto oficial da Secretaria da Educação de São Paulo. Consultas externas só exibem dados quando a sessão autenticada e as APIs responderem.
